# Integrated project review

[From PDF to evidence-grounded answer](05_end_to_end_system_evaluation.ipynb) is the single canonical notebook. It verifies committed source-bound reports, compares the selected reader's first pass and citation-guided reread, retains every question and error category, and explains the difference between development metrics and external closeout.

Run `make notebooks` in the locked environment before `make quality`. A fresh kernel produces and verifies outputs; unchanged reruns reuse only matching complete publications. The notebook contains no paid-workload launch controls and no private inputs.
